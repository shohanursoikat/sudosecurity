Method 1:
copy c:\windows\system32\sethc.exe c:\windows\system32\sethc.exe.bak //backup sethc file. Sethc: Sticky key is a win feature.
copy c:\windows\system32\cmd.exe c:\windows\system32\sethc.exe /y //override with cmd.

Press shift 5 times, CMD will open, then type:
net localgroup administrators //see localgroup admin.
net user hp * //change password.
exit

After logging in, go to the WinRE again. Open CMD and type:
copy c:\windows\system32\sethc.exe.bak c:\windows\system32\sethc.exe
del /s /q c:\windows\system32\sethc.exe.bak //delete the file.

Method 2:
copy c:\windows\system32\utilman.exe c:\windows\system32\utilman.exe.bak //backup utilman file. utilman.exe contains Windows accessibility features.
copy c:\windows\system32\cmd.exe c:\windows\system32\utilman.exe /y //override with cmd.

Click the Accessibility icon, CMD will open, then type:
net localgroup administrators 
net user hp * //change password
exit

After logging in, go to the WinRE again. Open CMD and type:
copy c:\windows\system32\utilman.bak c:\windows\system32\utilman.exe
Done.
